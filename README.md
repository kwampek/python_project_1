# Welcome to MyNotepad!
Простой в использовании текстовый редактор, поддерживающий базовый функционал.  

## Функционал

-   Графический интерфейс на основе модуля tkinter
-   Возможность редактирования файла
-   Перемещение по тексту при помощи “стрелок” - по словам, в начало/конец строки.
-   Удаление строк и слов
-   Текстовый поиск и замена
-   Хоткеи для сохранения и выхода

## Запуск
Запустите файл main.py любым способом!
